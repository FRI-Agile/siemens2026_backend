# Changelog

- **2026-10-12 · schema 0.1.0** — Initial documentation: conventions, templates.
- **2026-10-13 · schema 0.1.1** — Added the `kernel` schema (host-owned) with `kernel.idempotency`: HTTP `Idempotency-Key` claims and captured responses, `idx_idempotency_expires_at` for the daily `IdempotencyPruner` (03:00 UTC), the `idempotency_completed_has_status` CHECK and churn autovacuum settings — see ADR-D001. Landed in `configs/postgres/init/01-create-db.sql`, now loaded by the AppHost — see ADR-D002.
- **2026-10-21 · schema 0.2.0** — Added the `recruitment` schema with `recruitment.job_post` (title, location, department, description, draft/published, open positions, salary, payment type, employment type, the responsible recruiter as an Entra object id) and its `recruitment.set_audit_fields()` audit trigger — see ADR-D003 and ADR-D004. Schema listed in `infra/db-schemas.txt`.
- **2026-11-02 · schema 0.3.0** — `recruitment.job_post`: `is_published BOOLEAN` replaced by `status TEXT` (`draft` / `published` / `closed`, default `draft`) with the `job_post_status_valid` CHECK, for closing and reopening a post. Applied to an existing database by hand (ADR-D005): `ALTER TABLE recruitment.job_post ADD COLUMN status TEXT NOT NULL DEFAULT 'draft' CONSTRAINT job_post_status_valid CHECK (status IN ('draft', 'published', 'closed')); UPDATE recruitment.job_post SET status = 'published' WHERE is_published; ALTER TABLE recruitment.job_post DROP COLUMN is_published;`
- **2026-11-02 · schema 0.3.1** — The `pg_trgm` extension (in `public`) and the trigram GIN indexes `idx_job_post_title` and `idx_job_post_location` behind the job post lists' search, replacing the documented no-index deviation — see ADR-D006. Applied to an existing Azure database by hand: `just azure-deploy` (allow-lists `pg_trgm` in `azure.extensions`), `just azure-db-grant` (creates the extension), then as `healthyhires_app`: `CREATE INDEX idx_job_post_title ON recruitment.job_post USING gin (title public.gin_trgm_ops); CREATE INDEX idx_job_post_location ON recruitment.job_post USING gin (location public.gin_trgm_ops);`
